# CMIT 450 Project Brief: AvalonReach

## Problem

Choosing home internet is confusing because users must compare providers, speeds, prices, technology types, contracts, and availability by address. Provider sites are biased toward their own plans and do not always make tradeoffs obvious.

## Proposed solution

AvalonReach.com is a web application that lets users search a real address, view available internet providers, rank plans by personal priorities, and get a plain-English recommendation.

## Primary users

- Residents moving to a new address
- Current customers looking for better internet
- Remote workers and students who need reliable broadband
- Gamers/streamers who care about speed, upload, and latency

## Core features

1. Address search and availability lookup
2. Provider/result cards
3. Transparent recommendation scoring algorithm: cheapest, fastest, best value, upload priority, and gaming/remote work
4. Connection transport classification and explanations: fiber, cable/DOCSIS, fixed wireless, 5G home internet, DSL, traditional satellite, and LEO satellite
5. Lead capture and responder list
6. Basic account/dashboard for saved searches
7. Admin-ready provider referral links

## Stretch features

- AI-generated recommendation explanation
- Price history/deal alerts
- Provider affiliate/referral tracking
- Speed test comparison
- Local market landing pages
