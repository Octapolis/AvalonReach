# Working Notes

Working notes are the project trail: what we tried, what happened, what failed, what changed, and what we should do next.

Use these separately from weekly status reports:

- Status reports are polished summaries.
- Working notes are raw engineering history.

Suggested entry shape:

```md
## YYYY-MM-DD - Short Topic

Context:
- Why we were doing this.

Actions tried:
- What we changed/tested.

Result:
- What happened.

Issue / blocker:
- What did not work or what remains unclear.

Decision:
- What path we chose.

Next:
- Concrete follow-up.
```
