# Daily Working Notes

Daily working notes record the raw project trail by date.

Use these for actions tried, launch/test attempts, errors, blockers, suggested paths, decisions, and follow-up items.

Update flow:

1. Add the raw event to the relevant daily note.
2. If it creates or changes a bug, update `../../progress/known-issues.md`.
3. If it creates a possible improvement, update `../../progress/suggestions.md`.
4. If it changes roadmap status, update `../../progress/plan-progress.md`.

Daily notes are intentionally messier than weekly status reports. They are the receipts.
