# AvalonReach Project Notes

This folder keeps weekly project-status notes separate from product docs and implementation docs.

Use it for:

- AI recovery after context loss
- project covenant / mission alignment
- weekly CMIT 450 status reports
- raw working notes by week
- live-launch/testing notes
- blockers and decisions
- evidence checklists before submissions
- final-report source material
- resume/portfolio language
- reusable process notes for future builds

Rule of thumb:

- Start with `ai-recovery.md` after context loss or handoff.
- Start with `project-covenant.md` when the project needs mission/scope alignment.
- Put polished summaries in `week-XX-status.md`.
- Put attempts, failed paths, blockers, test results, and "what we tried" in `working-notes/daily/YYYY-MM-DD.md`.
- Update `progress/known-issues.md`, `progress/suggestions.md`, and `progress/plan-progress.md` when a daily note changes the project state.
