# Project Progress Trackers

This folder tracks the current state of AvalonReach across the project plan.

Use it with daily working notes:

- The covenant defines the mission and operating rules.
- Daily notes record what happened.
- Progress trackers show what is now true.

Files:

- `plan-progress.md` - progress against the 7-week plan.
- `known-issues.md` - bugs, blockers, gaps, and verification needs.
- `suggestions.md` - proposed improvements and next paths.

Update flow:

1. When a daily note adds an issue, add or update it in `known-issues.md`.
2. When a daily note creates a possible path, add or update it in `suggestions.md`.
3. When work changes milestone status, update `plan-progress.md`.
4. When an item is fixed, mark it fixed with the date and source note.
5. When a decision changes the mission, customer, promise, scope, or documentation workflow, update `../project-covenant.md`.
